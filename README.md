# 医考题库 PWA

面向 iPhone 的本地优先刷题应用，内置 3210 道医学题目。支持按科目组题、断点续刷、错题本、收藏、笔记、间隔复习、题库搜索及学习数据备份恢复。

## 在 iPhone 上安装

1. 使用 Safari 打开已发布的 HTTPS 地址。
2. 点击 Safari 的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 从主屏幕打开“医考题库”。首次完整加载后即可离线使用。

题库随应用缓存在手机中，学习记录保存在当前设备的浏览器存储中。换机、删除应用或清理 Safari 数据前，请在“设置与数据”中导出备份。

## 本地预览

Windows 下双击 `start_server.bat`，在同一台电脑打开显示的地址即可预览。局域网 HTTP 地址适合调试，不作为正式 PWA 安装地址；iPhone 正式安装请使用 HTTPS 发布地址。

## 构建

```powershell
npm install
npm run build
```

发布产物生成在 `dist`。
